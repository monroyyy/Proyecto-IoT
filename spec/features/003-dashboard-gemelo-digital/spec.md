# Feature 003: Dashboard y Gemelo Digital

## Descripción
Interfaz de usuario para visualizar en tiempo real el estado del TeleBrazo.

## Especificaciones
- Render 3D del brazo robótico (Gemelo Digital) que refleja ángulos reales.
- Gráficas de tiempo real para consumos de corriente y latencias.
- Componente de visualización de streaming de video de baja latencia.
